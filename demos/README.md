# Microsoft Fabric Demo - Business Stakeholder Showcase

A professional web application demonstrating Microsoft Fabric's capabilities using real-time GitHub data.

## 🎯 Business Value Proposition

**For Stakeholders:** This demo shows how Microsoft Fabric transforms raw data into actionable business insights in real-time.

## 🚀 Quick Start

### Prerequisites
- Python 3.7+
- Modern web browser

### Installation
```bash
# Navigate to project directory
cd d:\repos\cloudbaud\demos

# Install dependencies
pip install -r requirements.txt

# Run the demo
python app.py
```

### Access the Demo
Open your browser and go to: **http://localhost:5000**

## 🔧 Technical Architecture

### Medallion Architecture Demo
1. **Bronze Layer**: Raw GitHub Archive ingestion
2. **Silver Layer**: Structured data transformation
3. **Gold Layer**: Business-ready analytics aggregates

### Data Flow
```
GitHub Archive → Bronze (Raw) → Silver (Structured) → Gold (Analytics) → Dashboard
```
